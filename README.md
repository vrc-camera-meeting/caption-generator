# VRCカメラ集会 キャプション作成ツール

写真展に使うキャプション画像をブラウザーで作成できます。

https://vrc-camera-meeting.github.io/caption-generator/

## 使い方

1. 写真展と作品番号を選びます。
2. タイトル、撮影者、ワールド名などを入力します。
3. 「PNGを保存」でキャプション画像を保存します。
4. 保存したPNGで、Dropboxの同じ名前のファイルを上書きします。

写真からメタデータを読み込むこともできます。写真と入力内容はブラウザー内で処理され、サーバーには送信されません。

## 更新方法

元ファイル `D:\VRC_camera\World\tools\caption_generator.html` を編集した後、このリポジトリの `caption_generator.html` を差し替えて main ブランチへコミットします。
GitHub Pages は main ブランチのルートから公開します。
